# All-In

轻量级德州扑克房间，给朋友之间随便玩用的。浏览器打开就能进，不用装 App。

可以挂在云服务器上，也可以本机开着局域网一起玩。

## 功能

- 创建 / 加入房间（4 位房间码）
- 2–10 人一桌，No-Limit Texas Hold'em
- 初始筹码 2000；输光可补码 +2000（耻辱币），也可观战后再补
- 牌桌界面，手机和电脑浏览器都能玩

## 快速开始

需要 Node.js 18+ 和 Yarn。

```bash
yarn install
yarn start
```

默认监听 `0.0.0.0:5714`。

### 局域网

本机启动后，终端会打印类似：

```text
Friends on your LAN can open http://192.168.1.23:5714
```

朋友连同一个 Wi‑Fi，用这个地址打开即可。

### 云服务器

在服务器上同样 `yarn install && yarn start`。把 `5714` 端口对外开放（或前面挂 Nginx 反代），朋友用：

```text
http://你的服务器IP:5714
```

生产环境建议用进程守护，例如：

```bash
# 示例：用 PORT 环境变量覆盖默认端口
PORT=5714 yarn start
```

或配合 `pm2` / `systemd` / Docker 常驻运行。

## 怎么玩

1. 一人点「创建房间」，输入昵称，把房间码发给朋友
2. 其他人点「加入房间」，输入昵称和房间码
3. 满 2 人后，房主点开始

## 规则说明

- 玩码筹码，不是真钱
- 初始 **2000**，补码每次 **+2000**（只能在两手之间）
- 每次补码名字旁多一枚耻辱币
- 对局中断线视为弃牌
- 服务重启后房间清空（无持久化）
